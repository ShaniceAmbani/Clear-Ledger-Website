# Clear Ledger

Clear Ledger is a bookkeeping, tax compliance, and financial support company serving individuals, freelancers, and businesses across Kenya.

This website was designed and developed to establish the company's online presence, showcase its services, and provide an easy way for clients to make inquiries and request assistance.

## Live Website

https://www.clear-ledger.co.ke/

## Services Featured

* Bookkeeping Services
* KRA Services
* eTIMS Setup & Support
* Tax Compliance Assistance
* Financial Record Management
* Business Support Services

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern and user-friendly interface
* Service-focused business website
* Contact and inquiry functionality
* Formspree integration for client inquiries
* Fast and reliable deployment

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Formspree
* Vercel

## My Role

As the developer, I was responsible for:

* Designing and developing the website
* Creating a responsive user experience
* Implementing frontend functionality
* Integrating Formspree for contact form submissions
* Deploying and maintaining the live website
* Updating content and improving user experience

## Project Goal

The goal of this project was to create a professional digital presence for Clear Ledger and make it easier for potential clients to learn about available services and get in touch with the business.
